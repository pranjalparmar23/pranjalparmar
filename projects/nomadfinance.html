Overview

Project Overview

About 280 million people live and work outside the country they were born in. Together they send roughly $650 billion home every year, and about $41 billion of that is lost to fees. A worker who has just arrived somewhere new usually meets every problem alone: contracts in a language they cannot read, hidden exchange-rate markups, bad agencies, scam messages, and years of honest work that leave no financial record.

NomadFinance answers each of these with a Gemini-powered module, available in six languages as an installable PWA. The project lines up with UN Sustainable Development Goals 8 (decent work), 10 (reduced inequalities) and 16 (justice and strong institutions). I built it with two teammates, Devam and Aditya.

Capabilities

The Six Pillars

Remittance X-Ray

Ranks every provider by how much the family actually receives, using World Bank price data (221 provider records, 6 routes) and a four-provider live exchange-rate chain that fails over automatically.

Contract Shield

Upload a photo or PDF of a contract in any language. A Gemini pipeline reads it, compares each clause with 15 curated labor-law rules per host country, gives a Safe / Caution / Danger rating and writes a ready-to-send complaint letter.

Exploitation Radar

Anonymous reports about agencies and employers, matched by meaning with vector search, shown on a heat map with risk profiles. A scheduled job spots surges and alerts workers on the same route.

Financial Identity Builder

Turns logged income, bills, savings and transfers into a score and a plain-language story, with a PDF report that a bank or micro-lender at home can read.

Scam Check

Paste a message or upload a screenshot to get a verdict, the pressure tactics used, suspicious links and numbers (never opened) and three plain next steps. It scored 1.000 F1 on a 120-message, six-language golden set.

Financial Coach

A friendly interview that produces a 0 to 100 preparedness score and a 13-week plan with budget, cheapest remittance route and debt plan, plus day 30, 60 and 90 check-ins.

Trust & Safety

Built to Be Trusted

The AI never invents a number

The Coach score is plain Python, and every figure in a plan is derived from stored data and verified by code. A plan that fails the check is refused.

Messages are data, never instructions

User content is passed to Gemini as delimited data. A red-team run of 15 prompt-injection attacks in all six languages was resisted every time.

Private by design

Personal identifiers are masked before anything is saved or logged, contract files and screenshots are read once and discarded, and radar reporters are stored only as a keyed hash.

Ships dark, rolls back instantly

New modules sit behind Firestore feature flags. With a flag off, routes return 404 and the code is never downloaded, so rollback needs no deploy.

System Design

Architecture

A React PWA on Firebase Hosting talks to a Python FastAPI service on Cloud Run. The API stores data in Firestore (including vector search over report and scam embeddings), uses Gemini to read, sort, translate and explain, and relies on Cloud Scheduler for background jobs. Every route checks the caller's Firebase sign-in first.

One model per job

Code asks for a tier (reasoning, extraction, classification or embedding), and the Gemini model behind each tier is an environment variable. Every answer must fit a Pydantic model, with retries and per-feature token logging.

Five scheduled jobs

Exchange-rate refresh, radar surge aggregation, scam statistics, Coach check-ins and Financial Identity recompute, each behind a Google-signed token.

Tested and deployed with CI/CD

4,000+ backend tests, 1,600+ frontend tests and 14 browser test files, with 11 GitHub Actions workflows deploying through Workload Identity Federation and no stored keys.

Six languages, six countries

English, Hindi, Tagalog, Bahasa Indonesia, Nepali and Bengali, covering Singapore, South Korea, Malaysia, Japan, Hong Kong and Australia as host countries.
