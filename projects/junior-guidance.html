Overview

Project Overview

Junior Guidance is a full-stack web application designed to help students and junior developers gain knowledge about industry requirements with the help of seniors, who share their real-world experience as published articles on the platform. It supports proper categorization of content and role-based access control, so admins and regular users see and manage articles differently.

The backend is a Spring Boot REST API secured with JWT-based authentication, backed by MySQL through Spring Data JPA. The frontend is an Angular single-page application styled with Angular Material, and the whole stack is containerized with Docker Compose behind Nginx.

Capabilities

Key Features

JWT Authentication

Secure, stateless login backed by Spring Security, protecting all REST endpoints.

Role-Based Access Control

Separate Admin and User roles determine what content can be created, edited, or moderated.

Article Creation & Publishing

Seniors can write, publish, and update articles sharing real industry experience.

Category-Based Organization

Articles are organized by category so juniors can browse guidance relevant to their goals.

User Dashboard

A personalized dashboard for tracking published articles and platform activity.

Responsive UI

Built with Angular Material for a clean, consistent, mobile-friendly experience.

System Design

Architecture

Frontend

Angular single-page application (junior-guidance/) styled with Angular Material, communicating with the backend over REST.

Backend

Spring Boot REST API with Spring Data JPA for persistence and Spring Security (JWT) for stateless authentication and authorization.

Database

MySQL 8+ stores users, articles, and categories with role-based relationships.

Deployment

Fully containerized with Docker Compose, served behind an Nginx reverse proxy.
