Overview

Project Overview

This project designs and implements a solar panel cleaning and monitoring system with a customizable interface, aimed at optimizing cleaning schedules and tracking performance metrics. It works by monitoring pre- and post-cleaning readings of solar panels, giving a clear, data-backed view of how much cleaning actually improves panel output.

Capabilities

Key Features

Customizable Cleaning Schedules

An interface for configuring when and how often panels are cleaned.

Pre/Post-Cleaning Monitoring

Tracks performance metrics before and after each cleaning cycle.

IoT Sensor Integration

Captures live readings directly from the solar panel hardware.
